# Grão & Cia

Site criado no Micronuage.

## Como rodar

```bash
npm install
npm run dev
```

- `npm run build` — gera a versão de produção
- `npm test` — roda os testes

Feito com: React, Vite, TypeScript, Tailwind CSS, React Router.

## Pedido original

O que foi pedido quando o site foi criado na Micronuage:

> Crie uma loja virtual para a "Grão & Cia", que vende cafés especiais torrados. Deve ter catálogo de produtos com preço, página do produto, carrinho de compras e finalização de pedido por formulário. Visual quente e acolhedor.
